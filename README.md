# lab1-OOP
Цей проєкт показує, як писати сучасний код на Java — так, щоб він був коротким, зрозумілим і працював швидко. Ми використовуємо інструмент Lombok (щоб не писати багато нудного однотипного коду вручну) та Stream API (щоб легко і красиво працювати зі списками даних).
Що всередині проєкту?
Програма складається з трьох файлів:
User.java — це просто "шаблон" користувача. У ньому записано, що кожен користувач має id, ім'я, вік, вагу та зріст.
Car.java — такий самий "шаблон", але для автомобіля. У ньому записано марку, рік випуску, кінські сили тощо.
Main.java — це головний файл. Саме тут програма запускається і виконує 5 практичних завдань.
Що робить програма (5 завдань)
Коли ви запустите програму, вона по черзі зробить таке:
Завдання 1: Математика зі списками. Програма бере список чисел і за допомогою всього одного рядка коду рахує їхню суму та добуток. Жодних довгих і складних циклів!
Завдання 2: Склеювання тексту. Програма бере набір окремих слів і красиво зліплює їх у єдине речення, автоматично ставлячи між ними пробіли.
Завдання 3: Робота з людьми. Програма автоматично створює 10 різних користувачів (з різними іменами, віком і вагою). А потім — миттєво підраховує їхній загальний вік, вагу та зріст.
Завдання 4: Робота з машинами. Те саме, що й у третьому завданні, але тепер програма створює 10 машин і рахує їхню загальну потужність та об'єм двигунів.
Завдання 5: Перевертання числа. Невеличкий фокус: програма бере число (наприклад, 412), перетворює його на текст, розвертає задом наперед ("214") і знову перетворює на число.
Як це запустити?
Відкрийте проєкт у вашій програмі для написання коду (наприклад, IntelliJ IDEA).
Переконайтеся, що у вас працює плагін Lombok (зазвичай достатньо просто натиснути "Enable" у спливаючому віконці).
Відкрийте файл Main.java і натисніть зелену кнопку запуску (Run). Результат з'явиться внизу екрана.
